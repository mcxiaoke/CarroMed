# CHANGES 2026-10-08

## 11:28:40 — 修复后台常驻跨天今日 Tab 未自动更新到当天（方案 B）

- **问题根因**：
  - `TodayViewModel` 原判定条件仅在 `current > realToday` 时将选中日期拉回今天，跨天时由于前一日选中日期小于当前日期，被误判为“用户在看历史”，导致 `_selectedDate` 停留在昨日，药单清单及界面停留在过去。
  - `_selectedDate` 初始值与 `TodayUiState` 初始值此前直接读 `LocalDate.now()`，未与 `CurrentDateHolder.today.value` 严格对齐。
- **改动落实**：
  - `TodayViewModel`：增加 `onResume()` 生命周期回调，记录 `lastResumeDate`；当检测到从上次前台恢复后发生跨天（或选中落在未来）时，显式将 `_selectedDate` 归位为当天的最新日期；前台跨天时通过响应式流平滑自动推进。
  - `TodayScreen`：接入 `LifecycleResumeEffect`，页面恢复前台时触发 `CurrentDateHolder.refresh()` 并调用 `viewModel.onResume()`。
  - `CurrentDateHolder`：增加 `isPinnedForTest` 保护机制，防止单元测试钉死的桩日期被 `refresh()` 冲掉。
- **验证情况**：
  - 新增 `TodayViewModelDateRolloverTest`（4 项单测：跨天恢复自动归位、同日看历史不误复位、跨夜历史唤醒归位、前台自然跨天推进），全部通过。
  - 全量单元测试（`./gradlew testDebugUnitTest`）全部通过。
  - Release 构建（`./gradlew assembleRelease`）通过。
