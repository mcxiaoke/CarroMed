## 全屏提醒页面「忽略」重构为「关闭」，并全面落地 App 文案去工业化/温情化优化

时间戳：2026-10-18 14:43:12 (GMT+8)

### 变更摘要
1. **全屏提醒用词与操作重构**：
   - 深入评估全屏弹窗场景下的用户心智（药不在身边、手头有事暂不方便服用），将按钮文案从「忽略」正式重构为「关闭」（`alert_action_close` / `onClose`），契合“暂时收起界面、稍后回应用处理”的自然动作，彻底卸下系统指责感与误操作心理负担。
   - 保留原有的轻量关闭逻辑：发送 `Notifications.ACTION_DISMISS`，取消通知并销毁 Activity，不篡改槽位状态、不记录跳过事实。
   - 同步将设置页配置项更名为「未确认时重复提醒」（`set_repeat_reminder_title`），表意客观准确。

2. **系统性文案温情化落地（按 `docs/REPORT-COPYWRITING-IMPROVEMENT.md`）**：
   - **去考勤打卡化**：设置页「打卡确认服药」「完成服药打卡」改为平实自然的「确认服药」；连续服药徽章优化为「连续按时服药 X 天」。
   - **去工业/财务仓储术语**：将「账面待盘点」优化为「记录余量待校准」，引导按钮由「去盘点」优化为「去校准」，「请校准库存」优化为「请校准余量」；详情页「服药率」强化为医疗专有名词「服药依从率」。
   - **表达更温和/去绝对化**：今日页超时提示由「已过服药时间，待确认」调整为「已过计划时间 · 待确认」；未来日提示由「到达当天方可记录」调整为「到达当天即可确认」；保活指引将「灭屏休眠零漏报」改为客观平实的「确保手机息屏时准时提醒」；免打扰通知提示精简为「已开启夜间免打扰」。
   - **客观陈述事实**：将「过期请勿继续服用」优化为客观陈述「已过有效期」，避免过度替用户进行医疗训诫。

3. **测试、走查与视觉验证**：
   - 同步更新走查脚本 `scripts/app_screenshots.py` 断言文案与设置页下滑步骤。
   - 更新 `ComponentSnapshotTest` 快照测试调用。
   - 全量 616 项单元测试 `./gradlew testDebugUnitTest` 全绿通过。
   - `./gradlew assembleRelease` 发布构建与 lintVital 校验全部通过。

## 全屏 Alarm 支持设置可选开关，并将全屏页面「跳过本次」调整为「忽略」

时间戳：2026-10-18 14:08:15 (GMT+8)

### 变更摘要
1. **全屏 Alarm 开关设置化**：
   - 在 `ReminderSettings` 中补充 `KEY_FULL_SCREEN_ALERT` 与默认值（`DEFAULT_FULL_SCREEN_ALERT = true`），并将 `fullScreenAlert: Boolean` 属性纳入 `ReminderSettings.Behavior` 与 `resolve` 解析。
   - 在 `SettingsViewModel` 与 `SettingsUiState` 中增加 `fullScreenAlert` 状态字段、数据读取与变更持久化方法 `onFullScreenAlertChange`。
   - 在 `SettingsScreen`（设置页「通知与提醒行为」卡片）中增加「锁屏全屏提醒」Switch 开关，用户可自由控制到点提醒是否以全屏 Activity 弹出。
   - 在 `Notifications.showDoseNotification` 中，将全屏判断条件关联 `behavior.fullScreenAlert`。关闭后仅向通知栏发送普通通知横幅，不再触发 Full-Screen Intent。

2. **全屏页面操作优化（防误触）**：
   - 将 `AlarmAlertActivity` 与 `AlarmAlertContent` 中的「跳过本次」按钮替换为「忽略」（`alert_action_ignore`）。
   - 用户点击「忽略」时的行为：取消当前槽位通知（`cancelDoseNotification`），发送 `Notifications.ACTION_DISMISS` 广播，并立即关闭并销毁全屏页面（`finishAndRemoveTask()`）。
   - 不再向后台分发 `ACTION_SKIP`，不改动槽位状态为 SKIPPED，不记跳过事实，不扣库存，彻底避免用户在锁屏误操作导致不可逆跳过。

3. **测试与走查验证**：
   - 补充 `ReminderSettingsTest` 对 `KEY_FULL_SCREEN_ALERT` 行为解析的单元测试。
   - 更新 `ComponentSnapshotTest` 中 `AlarmAlertContent` 的回调参数调用。
   - 运行 `./gradlew testDebugUnitTest` 全量 616 项单元测试全绿通过。
   - 运行 `./gradlew assembleRelease` 验证 Release 构建与 lintVital 顺利通过。
   - 通过模拟器自动化走查验证 `09_settings.png` 与 `10_alarm_alert.png`，亲眼确认界面排版与文案生效，并实测点击「忽略」快速关闭退出且恢复前台。
