## 10:51 新增 APK 打包脚本（ABI 拆分产物入 dist/）

- 新增 `tools/package_apks.py`：一条命令打出 arm64-v8a / x86_64 / universal 三个包，
  以 `{app_name}-{abi}.apk` 命名（如 `CarroMed-arm64-v8a.apk`），
  输出到 `dist/{versionName}/`，并打印体积与 SHA-256。

  - app_name 从 `strings.xml` 读取，脚本不硬编码；
  - 支持 `--clean`（先 clean 再打包）与 `--debug`（打 debug 包）。
- `app/build.gradle.kts` 增加 ABI splits 配置，仅在传入 `-PabiSplits=true` 时启用，
  日常构建与 CI 不受影响。
- `.gitignore` 增加 `dist/`。
- 已实测：release 三包均产出并正确签名，落盘 `dist/1.0.1/`。
