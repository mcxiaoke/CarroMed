# CarroMed 最终设计 · 三：界面与交互 (FINAL-UI)

> **版本**：v3.1.0（原生 Jetpack Compose 终稿）
> **文档位置**：`docs/FINAL-UI.md`
> **性质**：本文档为**基于原生 Jetpack Compose + Material 3 的信息架构、视觉规范、页面与交互的唯一权威源**。取代 `UI_DESIGN.md`（v1.1，已废弃）。
> **模型依据**：所有页面元素均可在 `FINAL-ARCHITECTURE` 数据模型 v3.1 中找到落点，遵循“极简输入、字段预留大部可选”设计原则。

---

## 一、设计原则

1. **单手可达**：高频操作（打卡）全部落拇指热区；
2. **状态先行**：颜色只编码"状态"（正常/告警/严重），不编码药品类别；一切颜色必须配图标/形状冗余（色觉障碍友好）；
3. **老人友好**：默认字号偏大（可再放大）、按钮最小 48dp、防误触；
4. **无压迫感**：已完成的任务收起，页面只呈现"接下来该做什么"。

## 三、视觉规范

### 3.1 色彩

| Token | 浅色 | 深色 | 用途 |
| :--- | :--- | :--- | :--- |
| bg / surface | `#F8F9FA` / `#FFFFFF` | `#111418` / `#1B1F26` | 背景/卡片 |
| text 主/次 | `#1E293B` / `#64748B` | `#E2E8F0` / `#94A3B8` | 文本 |
| primary | `#2563EB` | `#60A5FA` | 品牌蓝（主按钮/选中态） |
| success | `#10B981` | `#34D399` | 已服/健康检查正常 |
| warning | `#F59E0B` | `#FBBF24` | 低库存/降级提醒 |
| danger | `#EF4444` | `#F87171` | 严重告警/负库存 |

规则：**深浅色双套 token 必须同时实现**；药品标识色由用户从色板自选（仅用于区分药品卡片，不承载语义）；状态色（success/warning/danger）不得被药品色占用。

### 3.2 图标与形状

- 药品图标 = **矢量剂型图标**（片剂/胶囊/口服液/滴剂/注射/外用，对应 `form` 字段），**禁用 emoji**（ROM 渲染不一致、无障碍差）；
- 打卡状态用圆环 Checkbox + 对勾形状冗余，不只靠颜色。

### 3.3 尺寸与页面架构规范

- **基准视口尺寸**：统一采用 **400dp × 854dp**（标准现代 Android 20:9 视口），Compose 预览与 HTML Demo 严格以此比例与热区尺寸对照开发。
- **全屏页面架构（摒弃半截体验）**：
  - **一级页面 (Tab)**：今日清单、我的药箱、进展追踪、统计报表（常驻底部导航栏）。
  - **二级独立全屏页 (Full-Screen Sub-Pages)**：药品专属详情页、添加/设置提醒计划页、手动补录服药页、补药入库页、系统设置页、保活自检页。进入二级页时**自动隐藏底部导航栏**，释放全部垂直可视空间，顶部统一提供返回导航条。
  - **唯一保留的半屏 Sheet**：通知快捷操作卡片（Quick Action Sheet，由锁屏或系统通知栏点按唤起，承载即时确认/推迟/跳过）。
- **组件尺寸**：卡片圆角 16dp，按钮 12dp/胶囊；外边距 16dp；触控热区与 Action 按钮 ≥ 48dp 高。

要点：

- **未确认区**：EXPIRED 槽位单独呈现（不冤枉为"漏服"），一键补录；
- 顶部周条可左右滑动查看前后日期（含月历入口）。

## 七、独立页面：添加与设置提醒计划页 (Add / Edit Schedule Screen)

系统化排程配置页面，解决多样化服药周期与低摩擦录入：

1. **基本信息（核心必填）**：
   - 药品名称 *（必填，如：环孢素）
   - 药品类别（常备药、慢病长期、抗生素短期、维生素补充等）
   - 剂型（药片、胶囊、口服液、滴剂、外用）
2. **提醒频次与时间方案（灵活定制）**：
   - 分段选择器：`[每天固定]` / `[隔天/隔N天]` / `[每周特定天]`
   - `每天固定`：快速设定 1次/2次/3次/4次，支持一键增减提醒时点与单次剂量。
   - `隔天/隔N天`：设定间隔天数（每隔 1 天、每隔 2 天、每隔 3 天等）。
   - `每周特定天`：周一至周日 7 曜多选（例如每周一、三、五）。
3. **闭环库存管理（可选折叠）**：
   - 当前现有库存、低库存预警阈值、包装规格（如 30片/盒）。
4. **说明与医嘱禁忌（可选折叠）**：
   - 详细用法描述（自由文本）。
   - 注意事项/禁忌标签（整粒吞服、禁酒、禁柚、随餐等）。
5. **历史数据安全保障（中途改计划）**：
   - 修改已有计划时，底部明示：“此前已打卡记录和库存流水 100% 完整保留，新计划从下次时点平滑生效”。

## 八、独立页面：系统设置页 (Settings Screen)

全局设置中心，包含五大模块：

1. **🔔 通知与提醒行为**：
   - 默认推迟时长（15分钟 / 30分钟 / 60分钟）。
   - 提醒铃声与震动模式（跟随系统 / 温和药铃 / 强提醒急促音）。
   - 灭屏全屏弹窗提醒（锁屏亮屏时直接显示快捷操作界面）。
   - 夜间免打扰静音（23:00 至 07:00 静音，早晨集中提醒）。
2. **🛡️ 提醒防漏与系统保活**：
   - 一键展开 4 项特权健康自检（精确闹钟、电池白名单、开机自启、通知显示）。
   - 国内主流 ROM（小米/华为/OPPO/vivo）后台加锁与自启指引。
3. **💾 数据管理与本地导出**：
   - 导出服药明细报表 (CSV)：明文格式，支持 Excel / WPS 直接导入。
   - 备份全量数据库 (JSON)：完整打包药品、排班、打卡明细与不可变库存流水。
   - 从备份恢复数据 (JSON)。
4. **ℹ️ 离线隐私承诺与关于**：
   - CarroMed v1.0.0 (Native Compose) 声明：无网络权限、无账号登录、无广告、纯离线。

## 十一、通知与快捷操作

- **单药通知**：标题=药名+剂量，正文=通知短句（`notice_short`），Action：已吃/推迟30m/推迟1h/跳过；
- **合并通知**（同时点多药）：一条通知折叠展示各药，Action：`全部已吃` / `推迟` / `跳过`；点开展开逐药操作；
- 锁屏隐私三档：完整 / 仅"该吃药了" / 静默（设置页配置，默认完整）；
- 点通知体拉起的快捷打卡半屏页：大按钮（确认吃药 60dp+）、推迟、跳过、改剂量——**尽力而为**，不可用时不影响通知 Action 主路径。

## 十二、边缘场景交互

| 场景 | 交互 |
| :--- | :--- |
| 误触打卡 | 5 秒 Toast Undo 窗口（"撤销 · 库存已加回"）；过期后从"已解决"区撤销，全程流水可查 |
| 当天已服改计划 | 暖色弹窗："今日 08:00 已服用 1 次，新计划自下次提醒生效，历史完整保留"；更早未服的槽位提示可补服 |
| 停药归档 | 有历史记录 → "删除"按钮替换为"停药并归档"；统计/历史中保留并标注"(已归档)" |
| 补录 | 表单选药→滚轮选过去时间→剂量→扣库存勾选；**若命中已有待服/未确认槽位则自动绑定**，提示"该时段已有待服计划，将直接完成该次" |
| 负库存 | 卡片黄底警示"库存 −2 片，请盘点"，打卡按钮不受任何影响 |

## 十三、Onboarding（首次启动，3 步）

1. **添加第一个药品**：预置常见药模板（分类/剂型/常用注意事项标签一键带入），也可空白新建；
2. **设时间与提醒**：保存排程时触发通知权限申请 + **提醒健康检查**（精确闹钟/电池白名单逐项引导，可稍后）；
3. **库存（可跳过）**：显式告知"库存功能可选，不填不影响提醒"。

空状态页：大 CTA"添加第一个药品"+ 一张示例卡片；首次备份提醒文案明示"数据仅存本机，卸载会清除，请定期备份"。

## 十四、提醒健康检查页

清单逐项检测（绿/黄/红），每项**一键跳转对应系统设置**（含厂商差异跳转映射）：

通知权限 · 通知渠道开启与重要性 · 精确闹钟权限 · 电池优化白名单 · 厂商自启动/关联启动 · 锁屏显示 · 勿扰例外。
页尾固定说明："强行停止应用后提醒将失效，请避免从最近任务中划掉本应用。"

## 十五、无障碍要点

- 所有交互控件配 contentDescription；圆环打卡态由 TalkBack 读出"羟氯喹，已服用"；
- 状态永不用颜色单独表达（形状+文字冗余）；
- 字号跟随系统缩放，布局在 200% 字号下不破碎；
- 触控目标 ≥ 48dp；打卡等关键操作无长按/滑动等精细手势依赖。
