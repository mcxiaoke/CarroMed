# 2026-10-17 变更记录

## 每日自动备份与备份文件混淆/防明文泄露

- **时间**：2026-10-17 22:36:30
- **需求**：
  1. 增加打开应用后每日自动备份功能，支持开关控制。
  2. 备份目录由用户通过系统选择器（SAF）选择，未设置目录或权限失效时不备份。
  3. 每日仅首次打开时自动备份一次，自动滚动保留最新的 10 份备份。
  4. 手动导出备份与自动备份文件格式改为 GZIP 压缩 + 固定异或 (XOR) + Base64 编码，防止敏感医疗/服药信息明文泄露，并保持对旧版明文 JSON 备份导入的 100% 向后兼容。

### 核心改动

1. **备份格式混淆与体积压缩 (`DataExporter.kt`)**：
   - 增加 `obfuscateBackup` 与 `deobfuscateBackup`：采用 GZIP 压缩 + 固定 XOR 掩码 + Base64 编码，生成带有 `CMBF01:` 前缀的密文格式。
   - `decodeBackup` 实现智能自适应解析：识别 `CMBF01:` 密文自动解混淆，遇到旧版明文 JSON 直接反序列化，实现完全向后兼容。
   - 导出后缀升级为 `.cbf`（CarroMed Backup File），同时在 `listLocalBackups` 中兼容 `.cbf` 和 `.json`。
   - 提供 `writeBackupToStream`，支持直接流式写入 SAF `OutputStream`。

2. **自动备份管理器 (`AutoBackupManager.kt`)**：
   - 新建 `AutoBackupManager` 单例，管理 `auto_backup_enabled`、`auto_backup_tree_uri`、`auto_backup_dir_name`、`auto_backup_last_date` 等设置。
   - `performAutoBackupIfNeeded`：严格校验开关开启、目录有效与持久化写权限（`isTreeUriPermissionValid`）；按 `today` 日期幂等防抖（每日仅首次触发一次）。
   - 滚动清理机制：自动备份完成后，检索符合 `CarroMed_AutoBackup_` 前缀的文件，字典序/时间降序排序，保留最新的 10 份，超出部分调用 `DocumentsContract.deleteDocument` 自动清理。

3. **设置界面与视图模型 (`SettingsViewModel.kt` & `SettingsScreen.kt`)**：
   - `SettingsUiState` 增加自动备份相关状态回显。
   - 支持 SAF `OpenDocumentTree` 目录选择，通过 `contentResolver.takePersistableUriPermission` 获得长效持久化权限。
   - 开关保护：若未选择目录时打开开关，自动拉起系统目录选择器；未选择目录时保持关闭，绝不盲目备份。
   - 恢复选择器 `backupPickerLauncher` 放宽 MIME 过滤为 `*/*`，支持用户自选 `.cbf`、`.json` 或任意后缀的备份文件。

4. **生命周期集成 (`MainActivity.kt`)**：
   - 在 `repeatOnLifecycle(Lifecycle.State.RESUMED)` 的 IO 协程中静默调用 `AutoBackupManager.performAutoBackupIfNeeded`，对主线程零阻塞，启动首屏零延迟。

5. **自动化测试守卫**：
   - 新增 `BackupObfuscationTest`：断言混淆产物不含任何敏感词、往返还原一致性、新旧备份格式双向兼容。
   - 新增 `AutoBackupManagerTest`：覆盖未开启跳过、未配置目录严禁备份、无权限拦截、当日已备份幂等跳过等全部分支。
