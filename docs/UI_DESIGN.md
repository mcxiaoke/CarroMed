## 一、设计理念与参考分析

### 1. 对比 MyTherapy 截图实测分析
* **保留精华**：
  * **今日清单**：顶部横向日期滚动条（周一~周日）可快速切换查看不同日期日程；
  * **时间分组**：按时间点由早到晚清晰分组（如 09:00, 13:30, 22:00）；
  * **进展图表**：以“周一到周日 7 天圆圈勾选”的直观矩阵展示单药打卡连击感；
  * **用药时间表**：支持随时设置每日多次、单次剂量与库存关联。
* **痛点改进与去冗余**：
  * **砍掉“支持” Tab**：MyTherapy 的第三个 Tab 是鸡肋的“支持/找亲友监督”，CarroMed 将其替换为更有价值的 **「统计」Tab (支持 1 个月/ 1 年用药汇总)**；
  * **简化字段复杂度**：药品仅需【名字、类别/种类、描述、颜色、单位与库存】，描述字段直接融合用法与注意事项，不用多层页面跳转；
  * **强化通知快捷弹窗**：点击通知栏直接呼出半屏浮窗，单手秒级完成“确认已吃 / 推迟30m / 推迟1h / 跳过”。

### 2. 融入主流 Todo / 习惯打卡设计哲学
* **极致高效的打卡动作**：卡片右侧放置大尺寸圆环 Checkbox，单指一触即完成，伴随轻微触觉震动反馈与折叠动画；
* **清晰的“已完成”区域**：打卡后平滑收入底部“已解决的任务”折叠面板，保持页面清爽无压迫感；
* **低库存预警提示条**：仅在库存低于预警线时，以柔和的琥珀色胶囊徽标提醒，不侵入主视觉。

## 二、视觉规范与色彩体系 (Design System)

### 1. 颜色体系 (Color Tokens)
* **背景主色**：`#F8F9FA` (极浅灰白，减少眼部疲劳，舒适柔和)
* **卡片底色**：`#FFFFFF` (纯白卡片，带 1px 细微边界线与柔和弥散阴影)
* **主文本色**：`#1E293B` (深岩灰，高对比度易阅读)
* **次文本色**：`#64748B` (浅石灰，用于剂量、时间与描述说明)
* **品牌基调色**：`#2563EB` (医护蓝，稳重、专业、安全)
* **药品语义点缀色（供用户自定义区分）**：
  * 💊 处方西药：`#3B82F6` (科技蓝)
  * 🌿 中成药/常备：`#10B981` (健康绿)
  * 🍊 维生素/保健：`#F59E0B` (活力橙)
  * 💜 激素/特定慢病：`#8B5CF6` (高贵紫)
  * 🌸 滴剂/外用药：`#EC4899` (柔和粉)

### 2. 圆角与间距规范
* **卡片圆角**：`16px`（现代圆润手感，符合 Material 3 规范）
* **按钮圆角**：`12px` 或全圆胶囊 `999px`
* **标准内边距**：外边距 `16px`，卡片内边距 `14px ~ 16px`

## 五、通知栏与快捷操作弹窗交互 (核心特性)

当 Android 闹钟定时器触发时，系统弹出高优先级横幅通知。用户点击通知或点击快捷按钮时呼出如下专用的 **快捷操作半屏界面 (Quick Action Sheet)**：

```
+─────────────────────────────────────────────────────────────+
|                                                             |
|                    (点击通知唤醒的快捷界面)                   |
|                                                             |
|      [ 💊 环抱素 ]             10:30 上午 (当前提醒)        |
|      剂量: 1 药片              当前剩余库存: 6 药片         |
|      💡 提醒注意: 固定时间服用，请用温水吞服                |
|                                                             |
|  +-------------------------------------------------------+  |
|  |           ✅ 确认吃药 (自动扣除 1 药片库存)            |  |
|  +-------------------------------------------------------+  |
|                                                             |
|  +---------------------------+ +-------------------------+  |
|  |      ⏰ 推迟 30 分钟       | |      ⏰ 推迟 1 小时     |  |
|  +---------------------------+ +-------------------------+  |
|                                                             |
|  +---------------------------+ +-------------------------+  |
|  |       ⏭️ 跳过本次服药      | |     ✏️ 调整剂量/写备注  |  |
|  +---------------------------+ +-------------------------+  |
|                                                             |
|                        [ 关闭窗口 ]                         |
+─────────────────────────────────────────────────────────────+
```

* **极速反馈**：
  * 点击「✅ 确认吃药」后，屏幕正中弹出轻量“已完成打卡，库存 -1”提示，同时播放柔和的打卡音效并震动，1 秒后自动关闭，用户几乎无需停留。
  * 点击「推迟 30m / 1h」，闹钟立即在后台重置，无多余确认步骤。

## 七、边缘场景防呆交互设计 (Edge Cases UX)

### 1. 误触打卡极速撤销 (1-Tap Undo with Toast)
* **交互路径**：
  * 用户在打卡后，若发现点错了，可在「已解决的任务」栏直接点击 **[↩ 撤销打卡]**；
  * 屏幕顶部立即弹出轻量 Toast：*“↩ 成功撤销打卡！库存已自动加回 1 片”*；
  * 任务恢复为待服状态，无需进入多层级页面。

### 2. 当天已服药、中途改计划的友好过渡弹窗 (Schedule Transition Modal)
* **触发场景**：
  * 今天 08:00 用户已打卡吃了 1 片药，上午 11:00 用户进入药品设置修改频次（如改为每天 3 次或今天暂停）。
* **UI 交互表现**：
  * 保存新排程时，系统弹出暖色提醒卡：
    > 🛡️ **历史数据保护提示**：  
    > 检测到您**今天 08:00 已服用过 1 次**。新计划将从**今天下午（下一次提醒）**开始生效；今日已服记录及过往全部历史**绝对保留，绝不丢失**！
  * 提供 [确认平滑更新] 按钮，消除用户对“改计划会不会把今天吃过的冲掉”的恐慌。

### 3. 停药与换药的归档交互 (Archive over Delete)
* **交互防护**：
  * 针对已产生过服药记录的药品，主界面将“删除”按钮替换为 **「停药并归档」**；
  * 归档后：从「今日」和「药箱主列表」移入“已归档”折叠区，关闭所有未来闹钟；
  * **在「统计」和「历史日历」中永久保留**，并标注“(已归档)”，确保年度吃药总数、医生就诊出示时数据完全连续真实。

### 4. 历史记录修正与差额平账 (Audit Log Correction)
* **交互路径**：
  * 在「进展/历史」列表中点击任意一条已完成记录，可弹出修改面板（修改实际服用时间、调整实际服用剂量）；
  * 若将 1 片改为 2 片，系统提示：*“剂量变动 +1 片，已为您自动补扣 1 片库存”*。数据账本始终保持平衡。
